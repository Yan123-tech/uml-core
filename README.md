# UML Core — справочник и тренажёр по лекциям ИТМО

Интерактивный конспект курса по моделированию ИС и UML (8 лекций): краткие выжимки, формальные определения, визуальные каталоги нотаций, глоссарий, флеш-карточки и рубежный тест — в одном самодостаточном HTML-файле без зависимостей и сборки.

**Демо:** [GitHub Pages](https://yan123-tech.github.io/uml-core/)

## Что внутри

- **8 лекций** — от моделирования ИС и требований до UML как языка и архитектурных представлений C4.
- **TL;DR** в начале каждой лекции — 3–4 тезиса-выноса и мост к следующей теме.
- **Карта раздела** — сворачиваемое дерево-миникарта; клик по узлу ведёт к блоку.
- **Формальные определения** — сворачиваемый блок точных формулировок из лекций (53 термина).
- **Попапы терминов** — ключевые слова подчёркнуты, при наведении всплывает определение.
- **Визуальные каталоги** — 73 SVG-карточки элементов всех диаграмм: use case, activity, классы, компоненты/развёртывание, состояния/последовательности, отношения UML, C4.
- **Глоссарий курса** — все термины с переходом к лекции.
- **Самопроверка** — 39 флеш-карточек и тест из 24 вопросов с фильтрами по лекциям и обоснованиями.
- **Прогресс изучения** — чекбоксы «Изучено» с сохранением в localStorage, поиск по разделам (`/`), тёмная тема.

## Структура репозитория

```
index.html        — справочник и тренажёр (весь UI в одном файле)
lecture-1..8.md   — полные конспекты лекций (первоисточник выжимки)
LICENSE           — MIT
```

## Как запустить

Файл самодостаточен — откройте `index.html` в браузере двойным кликом или:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Прогресс, тема и результаты теста хранятся в localStorage браузера.

## Источники

Материал конспектов и выжимки основан на лекциях курса [uml.itmo.is](https://uml.itmo.is/) (лекции 1–8 и связанные справочные материалы). Все 73 визуальных обозначения и определения терминов сверены с первоисточником.
